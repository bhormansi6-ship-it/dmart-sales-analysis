# Snapdeal Men's Sports Shoes Web Scraping

## Project Overview
This project uses Python to collect and analyze men's sports shoe product information from Snapdeal.

## Objectives
- Extract product names and brands.
- Collect original and discounted prices.
- Calculate discount percentages.
- Collect product ratings and review counts.
- Store the data in a CSV file.
- Analyze prices, discounts, and brand-wise product counts.

## Technologies Used
- Python
- Requests
- BeautifulSoup
- Pandas
- Matplotlib

## Project Files
- `snapdeal_scraper_capstone project.ipynb` — Jupyter Notebook containing the Python code.
- `snapdeal_mens_sports_shoes.csv` — Collected product dataset.

## Analysis
- Top brands by product count
- Average discounted price
- Average discount percentage
- Product price distribution

## Conclusion
This project demonstrates web scraping, data collection, CSV storage, and basic data analysis using Python.
