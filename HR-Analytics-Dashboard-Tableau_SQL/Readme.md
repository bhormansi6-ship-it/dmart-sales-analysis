📊 HR Analytics Dashboard (Tableau)

🔍 Overview

An interactive HR Analytics Dashboard developed using Tableau to analyze employee data and provide insights into workforce distribution, salary trends, and employee details. Designed with a professional corporate layout and interactive filtering for HR decision-making.

🎯 Key Features

KPIs

🔴 Total Number of Employees
🔴 Total Employee Salary
🔴 Total Working Hours
🔴 Total Leaves Taken

Visualizations

🔴 Average Salary by Job Category
🔴 Employees by Location
🔴 Employees by Job Category (Donut Chart)
🔴 Detailed Employee Information Table

Interactivity

🔴 Filters for Job Location and Job Category
🔴 Dynamic updates across all charts and KPIs

📂 Dataset

Employee-level data including:

Emp ID, Name, Company Name, Job Role, Job Category, Job Location, Working Hours, Salary Drawn, Leaves Taken,

🛠️ Tools Used

Tableau Desktop

🚀 Use Cases

🔷 HR Analytics
🔷 Workforce Planning
🔷 Salary Benchmarking
